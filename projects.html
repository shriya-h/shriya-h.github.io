tsllm (Taylor's Version)

View Repo

A character-level language model trained on Taylor Swift's complete discography. This project implements a generative transformer from scratch to mimic the lyrical patterns and themes of her music.

Key Features:
  • Decoder-Only Transformer: Implemented a generative architecture from scratch in PyTorch.
  • Custom Lyric Dataset: Automated preprocessing scripts to aggregate and clean lyrics from across all albums.
  • Character-Level Tokenization: Learns nuances of writing style at a granular level.
  • Interactive Training: Developed using Jupyter Notebooks for experimentation and output generation.
